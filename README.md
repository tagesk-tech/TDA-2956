# SF2956 human activity analysis

The analysis used Python 3.13 and the package versions in `requirements.txt`.

Run the analysis with the saved persistence features:

```bash
.venv/bin/python run_analysis.py
```

Recompute the persistence features from the sensor windows:

```bash
.venv/bin/python run_analysis.py --recompute
```

Open the presentation notebook:

```bash
./run_jupyter.sh
```
