\title{\textbf{Topological Signatures of Human Activity}\\
\large Persistent homology of delay-embedded smartphone sensors}
\author{SF2956 Project Group}
\date{September 2026}

\begin{document}
\maketitle

\begin{abstract}
We study whether the topology of short acceleration and gyroscope trajectories distinguishes six activities for people not used during model fitting. Each 2.56-second sensor window is mapped to a normalized delay-coordinate point cloud. Vietoris--Rips persistence in $H_0$ and $H_1$ is represented by four stable-rank functions, and the longest persistent $H_1$ class is additionally converted into a circular motion coordinate. Under one fixed subject-grouped evaluation protocol, delay topology obtains 0.580 balanced accuracy on nine disjoint test subjects, compared with 0.499 after time shuffling and 0.558 for unordered instantaneous topology. Restoring two discarded physical-scale values raises the score to 0.639. A compact 16-dimensional persistence-and-dynamics representation obtains 0.568, while the supplied 561 engineered features obtain 0.954. The topological construction therefore provides an interpretable description of temporal motion geometry, but it is not the strongest activity classifier.
\end{abstract}

\section{Introduction}

A smartphone sensor window is a short multivariate path, not merely an unordered sample from $\mathbb R^3$. Walking and static posture can differ in amplitude, but also in the geometry traced through time. We represent this geometry using delay coordinates and then follow the course pipeline from a finite metric space to Vietoris--Rips persistence and stable ranks \cite{course-notes}.

The project asks one primary question:

\begin{quote}
Does the topology of short acceleration and gyroscope trajectories contain activity information that transfers to people not used for training?
\end{quote}

Two secondary questions make the result interpretable. First, does any information disappear when temporal order is destroyed? Second, can a persistent loop be converted into a circular coordinate describing periodic motion? The objective is not to outperform engineered activity-recognition features. It is to identify what this topological representation measures and where information is lost.

Earlier versions of the project accumulated many classifiers, parameter searches, metric couplings, and statistical comparisons. The present analysis deliberately contains five topological representations, one fixed model, one grouped development protocol, and one official subject-disjoint evaluation. Since earlier project iterations had already inspected the official test results, those results are descriptive rather than a new confirmatory test.

\section{Data and sampling structure}

The UCI Human Activity Recognition Using Smartphones dataset contains 30 volunteers performing walking, walking upstairs, walking downstairs, sitting, standing, and laying \cite{uci-paper}. Triaxial body acceleration and angular velocity were sampled at 50 Hz and divided into 128-sample windows with 50\% overlap.

The supplied split assigns complete people to development or test data. This avoids the direct leakage that would occur if overlapping windows from one person appeared on both sides of a random window-level split.

\[

\]

\section{Topological construction}

\subsection{Delay-coordinate metric spaces}

For embedding dimension $m$ and lag $\ell$, define
\[
E_{m,\ell}(x)_t=
\bigl(x_t,x_{t+\ell},\ldots,x_{t+(m-1)\ell}\bigr)
\in\mathbb R^{3m}
\]
for $t=0,\ldots,127-(m-1)\ell$. The representing finite set is
\[
X_{m,\ell}(x)=\{E_{m,\ell}(x)_t\}.
\]
Delay coordinates are motivated by reconstruction ideas from dynamical systems \cite{takens}, but no exact Takens reconstruction claim is made for these finite, noisy and preprocessed paths.

We fix $m=3$ and $\ell=15$, producing 98 points in $\mathbb R^9$. The lag is the first non-positive value of the mean normalized acceleration autocorrelation on the development data (Figure~\ref{fig:lag}); it is not selected using classification accuracy.

\begin{figure}[H]
\centering
\includegraphics[width=0.72\textwidth]{lag.pdf}
\caption{Mean development-set acceleration autocorrelation. The first non-positive value occurs at 15 samples, or 0.30 seconds.}
\label{fig:lag}
\end{figure}

For a cloud $X=\{z_1,\ldots,z_n\}$, define
\[
\bar z=\frac1n\sum_i z_i,
\qquad
r(X)=\left(\frac1n\sum_i\lVert z_i-\bar z\rVert_2^2\right)^{1/2},
\]
and normalize by
\[
\widetilde X=\left\{\frac{z_i-\bar z}{r(X)}\right\}_{i=1}^n.
\]
Thus the primary topology is invariant to translation and positive global rescaling. The two sensor radii are retained separately for one explicit comparison rather than being silently mixed into the normalized topology.

\subsection{Vietoris--Rips persistence}

For finite metric space $(X,d)$ and scale $\epsilon\geq0$, the Vietoris--Rips complex is
\[
\operatorname{VR}_\epsilon(X)=
\{\sigma\subseteq X:d(x,y)\leq\epsilon\text{ for every }x,y\in\sigma\}.
\]
Because $X$ is finite, the filtration is tame \cite[Points 187--193]{course-notes}. We compute persistence diagrams $D_0(X)$ and $D_1(X)$ over $\mathbb F_{47}$ using Ripser.py \cite{ripserpy}. Here $H_0$ records how connected components merge and $H_1$ records loops. The field is shared with the circular-coordinate extension so that one persistence call supplies both representations.

Figure~\ref{fig:construction} shows one walking acceleration window. Only the first three of nine delay coordinates are drawn; persistence is computed from the full Euclidean geometry.

\begin{figure}[H]
\centering

\caption{A normalized delay cloud and its finite $H_0$ and $H_1$ persistence diagrams for one development window.}
\label{fig:construction}
\end{figure}

\subsection{Stable ranks}

For finite diagram $D_k$, the lifetime stable rank is
\[
\rho_k(u)=\#\{(b,d)\in D_k:d-b>u\},\qquad u\geq0.
\]
We evaluate this function with StableBear \cite{stablebear,stable-rank} on the fixed grid $u_j=2j/63$, $j=0,\ldots,63$. One window becomes
\[
\Phi_{\mathrm{SR}}(x)=
[\rho^{(a)}_0,\rho^{(a)}_1,\rho^{(g)}_0,\rho^{(g)}_1]
\in\mathbb R^{256}.
\]
Infinite $H_0$ classes are removed. The blockwise numerical distance used later is
\[
d_{\mathrm{SR}}(f,g)=
\sum_{b=1}^{4}\frac{2}{63}\sum_{j=0}^{62}
|f_b(u_j)-g_b(u_j)|.
\]
Computing the integral separately for each block is important: each block has its own right endpoint.

\begin{figure}[H]
\centering
\includegraphics[width=0.88\textwidth]{stable_ranks.pdf}
\caption{Mean stable ranks by activity. Dynamic and static activities differ broadly, while similar activities overlap.}
\label{fig:stable-ranks}
\end{figure}

\subsection{Persistent circular coordinates}

Stable ranks count lifetimes but discard the birth scale and identity of a particular loop. We therefore retain six direct summaries per sensor: mean and maximum finite $H_0$ lifetime, number of $H_1$ classes, longest $H_1$ lifetime, total $H_1$ persistence, and birth of the longest class.

For the longest $H_1$ bar $(b^*,d^*)$, Ripser also returns a cocycle $\alpha$ over $\mathbb F_{47}$. We evaluate it on the Rips graph at
\[
\epsilon^*=b^*+\tfrac12(d^*-b^*)
\]
and lift its coefficients to centered integers. If $B$ is the oriented edge--vertex incidence matrix, fix the first vertex and solve
\[
\widehat\phi=
\arg\min_{\phi:\phi_0=0}\lVert B\phi+\alpha\rVert_2^2.
\]
The circle-valued coordinate is $\theta_i=\widehat\phi_i\bmod1$ \cite{circular-coordinates}. Unwrapping $2\pi\theta_i$ in delay-point order and regressing it on $t_i=i/50$ yields circular frequency $|\widehat\beta_1|/(2\pi)$ and phase linearity $R^2$. Together with the six diagram summaries, this gives eight features per sensor and 16 per window.

\section{Experimental design}

The comparison contains exactly five topological representations:
\begin{enumerate}
  \item instantaneous TDA: $m=1,\ell=1$;
  \item delay TDA: $m=3,\ell=15$;
  \item shuffled-delay TDA: independently permute each window before the same delay construction;
  \item delay TDA plus the two sensor radii;
  \item the 16 compact persistence-and-dynamics features.
\end{enumerate}
The shuffled control preserves the multiset of three-dimensional samples while destroying temporal adjacency. The supplied 561 UCI features are included once as a non-topological reference.

Every representation uses the same pipeline:
\[
\operatorname{StandardScaler}\longrightarrow
\operatorname{RBF\ SVM}(C=10,\gamma=0.001,
\text{class-weight=balanced}).
\]
The parameters are frozen from earlier development work. We perform no representation-specific tuning. Development predictions use five stratified subject-grouped folds with seed 2956; the fitted model is then evaluated once on the supplied disjoint test subjects. Balanced accuracy is primary because activity counts differ, and macro F1 is secondary. Scikit-learn supplies the model and grouped folds \cite{scikit-learn}.

Delay topology exceeds shuffled-delay topology by 0.081 test balanced-accuracy points. This supports the claim that temporal adjacency contributes to the delay-cloud topology. Delay also exceeds instantaneous topology by 0.022, but this smaller descriptive difference alone is not strong evidence that delay embedding is always preferable.

Restoring only the two RMS radii raises the delay score from 0.580 to 0.639. Normalization therefore removes physical amplitude that is useful for activity recognition. This is not a defect in the construction: it exposes the distinction between normalized shape and scale.

The 16-dimensional dynamics vector reaches 0.568. It is competitive with the 256-dimensional stable-rank vector but does not exceed it under the shared fixed classifier. The earlier, higher dynamics result depended on representation-specific tuning; removing that tuning changes the conclusion. The engineered UCI features remain substantially stronger at 0.954.

\subsection{Cross-subject stable-rank geometry}

For development subject $p$ and activity $c$, define
\[
\mu_{p,c}=\frac{1}{N_{p,c}}
\sum_{i:p_i=p,y_i=c}\Phi_{\mathrm{SR}}(x_i).
\]
Figure~\ref{fig:geometry} averages $d_{\mathrm{SR}}(\mu_{p,c},\mu_{q,c'})$ across distinct subjects. The mean diagonal distance, comparing the same activity across people, is 13.75. The mean off-diagonal distance is 18.87, a ratio of 1.37. Walking is closest to walking downstairs, and sitting is closest to standing. The geometry therefore recovers a broad dynamic--static division without another classifier, while also showing substantial subject variation.

\subsection{Circular motion summaries}

Figure~\ref{fig:dynamics} shows four directly interpretable components of the compact representation. The dynamic activities have higher mean circular frequency than sitting, standing and laying. Phase linearity is also generally higher for periodic walking motion. These quantities describe the phase of a selected persistent loop; they are not identical to a Fourier peak and should not be interpreted as a complete physical gait frequency.

\subsection{Bounded perturbation check}

We select ten development windows per activity and add independent Gaussian noise with standard deviation equal to 5\% of each window and channel's empirical standard deviation. After complete recomputation, the mean stable-rank displacement is 2.61, with empirical 2.5\% and 97.5\% quantiles 1.86 and 4.19. This is about 19\% of the mean same-activity cross-subject distance. The result illustrates gradual movement under perturbation, consistent with the Rips stability mechanism in the course notes \cite[Point 197]{course-notes}; it is not a proof of a stability theorem.

\section{Discussion}

The clean analysis supports three main conclusions. First, normalized delay topology contains activity information that transfers between subjects. Second, destroying temporal adjacency reduces performance, so the representation is not merely detecting an unordered distribution of samples. Third, normalization deliberately removes important amplitude information, visible in the improvement from adding two explicit radii.

The topological representation is most useful as an interpretable structural description. The stable-rank geometry places dynamic and static activities into broad families, while the circular coordinate connects a persistent loop to ordered phase progression. These are meaningful TDA results even though ordinary engineered features classify much better.

There are important limitations. The official test was inspected during earlier project iterations, so its scores are descriptive. The fixed SVM parameters also originate from that exploratory work. Windows overlap within subjects, although subject-grouped validation prevents a person from appearing in both fitting and validation folds. Stable ranks discard bar births and correspondence between classes. Finally, a circular coordinate derived from the longest $H_1$ class can be unstable when several loops have similar persistence or when no clear periodic class exists.

The deliberately omitted analyses are also informative. Large parameter grids, multiple sensor-coupling metrics, extensive ablations and repeated uncertainty calculations made the previous implementation difficult to audit without changing the core conclusion. They are not required to demonstrate the course pipeline. Future work should begin with new subjects or a genuinely untouched dataset rather than expanding the current search space.

\section{Reproducibility}

The analysis is specified mathematically in \texttt{ANALYSIS\_SPEC.md}. Four small Python files load the data, construct topological features, evaluate one fixed model, and run the analysis. The primary delay persistence is computed once per window and reused for stable ranks and circular dynamics. Direct compressed NumPy caches avoid recomputing persistence; fitted models are not serialized.

From the project root:
\begin{verbatim}
.venv/bin/python -m unittest -v test_math.py
.venv/bin/python run_analysis.py --smoke --recompute
.venv/bin/python run_analysis.py
.venv/bin/python build_notebook.py
\end{verbatim}

The cold full run completed in 8 minutes 33 seconds on the development machine. The smoke run completed in approximately ten seconds. All nine mathematical and data-contract tests pass, and the generated notebook executes all ten code cells from a fresh kernel.

\section{Conclusion}

Delay-embedded smartphone sensors produce persistent topological structure that generalizes across people. Time shuffling lowers stable-rank classification, while adding back two explicit physical scales improves it. Persistent circular coordinates provide a compact description of periodic motion but, without representation-specific tuning, do not outperform the stable-rank vector. The supplied engineered features remain far stronger. The contribution is therefore a small, auditable TDA account of motion geometry and temporal structure rather than a claim of state-of-the-art activity recognition.
